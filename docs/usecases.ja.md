# ユースケース

本プロジェクトは Schelling (1971) "Dynamic Models of Segregation" の3つのモデルをすべて再現実装しています．以下に代表的な利用シナリオと，各々の詳細ドキュメントへの入口を示します．

## 1. 空間分離の再現（空間近接モデル）

「近隣の少なくとも1/3は同色であってほしい」という穏やかな個人選好が，2次元グリッド上でマクロレベルの顕著な分離を生む様子を観察します．これが論文の核心的知見です．

- 単発のシミュレーション実行：[CLI — `run`](cli.ja.md#run-空間近接モデル) を参照．
- 論文の図（Fig. 7–32）を再現し報告値と比較：[論文再現](reproduction.ja.md) を参照．
- グリッド進化と分離度指標の可視化：[可視化](visualization.ja.md) を参照．

## 2. パラメータ感度（スイープ）

許容限界 τ と空き地率を掃引し，均衡分離度がどう応答するかを調べます．スイープはミクロ選好とマクロ結果の強い非線形性を明らかにします．

- グリッドサーチの実行：[CLI — `sweep`](cli.ja.md#sweep-パラメータスイープ) を参照．
- 1次元の折れ線・2次元のヒートマップの可視化：[可視化 — スイープ](visualization.ja.md#スイープ結果の可視化) を参照．

## 3. 位相平面解析（境界近隣モデル）

状態を集計人口 $(W, B)$ に縮約し，許容限界スケジュールから反応曲線を導出して，位相平面で動学（平衡点・安定性・ベクトル場・軌跡・吸引域）を解析します．

- 解析モデルの実行：[CLI — `bnm` / `bnm-basin`](cli.ja.md#bnm--bnm-basin-境界近隣モデル) を参照．
- 位相図・吸引域の可視化：[可視化 — BNM](visualization.ja.md#解析モデル可視化-bnm--tipping) を参照．

## 4. ティッピング動学（ティッピングモデル）

BNM を住宅市場に応用してティッピングを調べます：投機的移動，非対称な流入/退出，結果の類型分類（in-tipping / out-tipping / both / neither — 典型的なホワイトフライト）．

- ティッピングモデルの実行：[CLI — `tipping`](cli.ja.md#tipping-ティッピングモデル) を参照．
- ティッピング類型の可視化：[可視化 — Tipping](visualization.ja.md#解析モデル可視化-bnm--tipping) を参照．
